# Branding & Design Portfolio — GitHub Pages

1. Upload `index.html` and the complete `assets` folder to a GitHub repository.
2. Open repository **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
4. Link the published page from Google Sites as **Branding & Design**.

The ISD slideshow uses selected rendered pages from the uploaded March 2025 Brand Identity Guidelines. YouTube autoplay is muted (browser restriction); Facebook Reels open in a new tab.
